# User Stories 

Format: As a [type of user], I want [goal], so that [reason or benefit].

1. As a maintenance technician, I want to view real time temperature sensor readings on the M5Stack Cardputer so that I can monitor equipment conditions while moving around the facility. I also want to review historical temperature data so that I can analyze trends, detect abnormal temperature changes, and identify recurring issues.
2. As a system operator, I want to receive alerts when temperature readings exceed predefined thresholds or change rapidly so that I can take immediate action to prevent equipment damage, overheating, or system failure.
3. As an engineer, I want to view the operational status of connected temperature monitoring IoT devices so that I can quickly identify sensor malfunctions, communication failures, or disconnected devices.
