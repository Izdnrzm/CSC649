# Requirements

## Functional requirements (what the system must DO)
1. The system shall collect sensor data from connected IoT devices.
2. The system shall transmit sensor data wirelessly to the M5Stack Cardputer.
3. The system shall display real time sensor readings on the Cardputer screen.
4. The system shall alert users when sensor values exceed predefined thresholds.
5. The system shall allow users to view the status of monitored devices.

## Non-functional requirements (how the system must PERFORM)
1. The system shall update sensor data on the M5Stack Cardputer within 3 seconds of receiving new readings.
2. Alert notifications shall be displayed to the user within 3 seconds after a sensor value exceeds its predefined threshold.
3. The wireless communication between IoT devices and the Cardputer shall achieve a data transmission success rate of at least 95%.
4. The Cardputer user interface shall display all critical monitoring information on a single screen with text size of at least 12 pixels for readability.
