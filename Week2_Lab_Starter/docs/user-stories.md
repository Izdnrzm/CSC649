# User Stories

Format: As a [type of user], I want [goal], so that [reason or benefit].

1. As a maintenance technician, I want to view real time sensor readings on the M5Stack Cardputer so that I can monitor equipment conditions while moving around the facility. Also I want to review previously recorded sensor data so that I can analyze trends and identify recurring issues.
2. As a system operator, I want to receive alerts when sensor values exceed predefined thresholds so that I can take immediate action to prevent equipment failure.
3. As an engineer, I want to view the operational status of connected IoT devices so that I can quickly identify communication or device failures.
